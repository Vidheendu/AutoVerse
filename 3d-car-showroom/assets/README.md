# Assets Directory

This directory is designated for external 3D models, textures, environment maps, and audio assets.

### Phase 2 Preparation
In Phase 2, 3D vehicle assets will be added here:
- **Formats supported:** `.glb` (recommended binary glTF), `.gltf`
- **Recommended model specs:**
  - Optimization: Low to medium polycount (~50,000 to 150,000 triangles) for smooth WebXR 60-90 FPS.
  - Materials: PBR (Physically Based Rendering) with Metallic-Roughness workflow.
  - Textures: 1024x1024 or 2048x2048 resolution.

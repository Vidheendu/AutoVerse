# Assets Directory

This directory stores 3D models, textures, environment maps, and vehicle assets for AutoVerse VR.

## 🚗 Car Models Directory (`assets/cars/`)

All 7 showroom vehicles are managed under `assets/cars/` using standard binary glTF (`.glb`):

| # | Vehicle | Category | File Name | Status |
|---|---|---|---|---|
| 1 | BMW M4 | Sports Coupe | `bmw-m4.glb` | ✅ Loaded & Calibrated |
| 2 | Mercedes-AMG GT | Luxury Sports | `mercedes-amg-gt.glb` | 📥 Place GLB in this folder |
| 3 | Porsche 911 | Performance | `porsche-911.glb` | ✅ Loaded & Calibrated |
| 4 | Audi R8 | Supercar | `audi-r8.glb` | ✅ Loaded & Calibrated |
| 5 | Lamborghini Huracán | Supercar | `lamborghini-huracan.glb` | 📥 Place GLB in this folder |
| 6 | Range Rover Sport | Luxury SUV | `range-rover-sport.glb` | 📥 Place GLB in this folder |
| 7 | Ford Mustang | Muscle Car | `ford-mustang.glb` | 📥 Place GLB in this folder |

### How to Add Missing Models
Simply drop the corresponding `.glb` file into `assets/cars/` using the exact file names above. The showroom automatically loads and renders them on their respective platforms without changing any code.
